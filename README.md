# Video Edit Agent

A local app for a video agency. You put raw footage and references in a folder, describe the video you want, and an AI agent plans a 1080x1920 (vertical, 30 fps) edit with captions, music and narration. A built-in renderer produces the MP4. You then fix single segments with plain-language feedback; approved parts never change.

## Bắt đầu nhanh (Tiếng Việt)

1. Cài Node.js 20+, ffmpeg (có ffprobe), yt-dlp, whisper.cpp (`whisper-cli`) cùng một file model, và có sẵn khóa AI (Claude).
2. Trong thư mục dự án chạy: `npm install`, rồi `npm run build:web`, rồi `npm start`.
3. Mở http://127.0.0.1:4317. Giao diện mặc định là tiếng Việt (có thể đổi sang English trong Cài đặt).
4. Vào Cài đặt: dán khóa AI (được lưu vào tệp `.env` của ứng dụng, biến `AI_PROVIDER_KEY`), nhập đường dẫn `whisper-cli` và file model Whisper.
5. Tạo thư mục dự án gồm `raw/` (cảnh quay thô) và `reference/` (nhạc, giọng đọc, video mẫu, kịch bản), chọn thư mục đó trong ứng dụng, viết yêu cầu, kiểm tra vai trò của từng file tham chiếu, rồi bấm tạo video.
6. Xem video, gõ góp ý (ví dụ "đổi cảnh ở 0:03"), duyệt (khóa) những đoạn đã ưng ý, hoặc quay lại phiên bản cũ.
7. Lần dựng đầu tiên trên một máy cần internet một lần để Remotion tải trình duyệt của nó. Chỉ khung hình mẫu và bản ghi lời thoại được gửi cho AI; video gốc luôn ở trên máy bạn.

## What it does

1. You register a project folder. The app scans it, downloads reference links (YouTube and TikTok, with yt-dlp), cuts every video into shots, takes sample frames and transcribes speech locally with whisper.cpp.
2. It proposes a role for each reference file (narration, music, style, script, ignore). You can edit the roles before generating.
3. The agent (Anthropic API) writes a timeline: segments of your raw footage, captions, the music or narration track, transitions and effects. A built-in Remotion renderer turns it into `v1.mp4`.
4. You give feedback on the result. A fix changes only what the feedback points at, saves a new version and renders it.

The agent never edits video itself; it writes and patches a timeline (all times are integer frames at 30 fps), and the code enforces the rules.

## Requirements

- Node.js 20 or newer
- `ffmpeg` and `ffprobe` on PATH
- `yt-dlp` (only for links in `reference/links.txt`)
- whisper.cpp `whisper-cli` and a Whisper model file (local transcription)
- An AI key (Claude, from the Anthropic Console)

## Install and run

```
npm install
npm run build:web
npm start
```

Open http://127.0.0.1:4317. The server listens on 127.0.0.1 only and has no login; do not expose it. `VEA_PORT` changes the port. Everything is configured in the Settings page:

- **AI key** is stored in the app folder's `.env` file as `AI_PROVIDER_KEY` (mode 0600, git-ignored). You can also copy `.env.example` to `.env` and fill it in by hand; edits apply without a restart. If `.env` has no key, an `AI_PROVIDER_KEY` set in the system environment is used. The page shows only the last 4 characters and says where the current key comes from. A key left in `settings.json` by an older version is moved into `.env` at startup.
- **Everything else** (model, language, Whisper binary and model paths, yt-dlp path, token prices) is stored in `~/.vea/settings.json` (mode 0600).

How it is built and what happens at each step: [docs/architecture.md](docs/architecture.md).

## Project folder layout

```
my-project/
  guideline.md          brand and style rules, and notes on reference files (optional, create from a starter in the UI)
  raw/                  your raw footage (mp4, mov, mkv, webm, mp3, wav, m4a, aac)
  reference/            music, narration, sample videos, script files (.txt, .md, .srt), logo images (.png, .jpg, .jpeg, .webp)
    links.txt           one reference URL per line (YouTube or TikTok are downloaded)
  .vea/                 generated by the app: analysis cache, downloads, videos and their versions
```

Starters for `guideline.md` (real estate, trend, vlog; Vietnamese and English) are in `starters/`. Paths in timelines are relative to the project folder. File names with Vietnamese characters work whether the file system stores them composed (NFC) or decomposed (NFD).

Logos: put the logo file in `reference/` (PNG, JPG or WebP) and name it in `guideline.md` (the starters have a line for it). A logo overlay may use only an image found in `reference/`; any other file is sent back to the agent before anything is rendered. Images get no reference role.

If none of the files in `raw/` can be read, the project is refused (`NO_RAW_FOOTAGE`, naming each file) before any AI call.

## Order of authority

When instructions disagree, the higher one wins:

1. System rules (built into the app: locks, output format, privacy)
2. `guideline.md`
3. Your prompt
4. The agent's own guess

A prompt instruction that loses to a higher source is not silently dropped: it is listed under "not followed" with the reason.

## Reference roles

Each file in `reference/` (and each downloaded link) gets a role: narration, music, style, script or ignore. The defaults are guesses from the content: a video is a style sample, the longest speech audio is the narration, music audio is music, silent or unclassifiable audio is ignored, text files are scripts. The AI may change a default only when the guideline or your prompt says so, and each role shows who decided it (guideline, prompt or guess) and why.

To override a role for good, write it in `guideline.md`, for example:

```
## Reference usage
- `track.mp3` is music, not narration.
- `sample1.mp4`: copy the caption style only.
- `intro.mp4`: copy the opening structure, do not use its footage or audio.
```

You can also change any role by hand in the UI before generating. A style reference's own audio is used only when the guideline or the prompt explicitly says so.

Timing follows, in order: narration if there is one, speech in the raw footage, music, otherwise the pace of the footage.

## Fixes, approval, versions

- Feedback may name times such as "swap the shot at 0:03". The agent may then change only the segment (and captions) covering that time.
- Approve (lock) a segment or caption in the segment list. Approved items never change. A fix aimed only at approved items is refused. Approving saves a new version but does not re-render.
- Without unlock, no segment boundary and no total duration changes, and music and narration never move. If a fix can only be done by changing a duration ("make it shorter"), it is refused and the UI offers Unlock; with unlock the target segments may be retimed and later ones shift. Approved items still never change.
- Every generate, fix, approval and revert makes a new version; nothing is overwritten. Reverting to version N saves version N's content with the approvals of the latest version as the newest version and renders it. If an item approved now is missing or different in version N, the revert is refused and nothing is saved; the UI names those items by time so you can remove their approval first.
- After a fix the UI lists what changed with its time (for example "Changed: 0:06 shot, 0:06 caption"); the version note lists the changed ids. A refusal is shown in the UI language; when the agent itself declines, its reason is in the language of your feedback.
- With unlock, shortening a segment also squeezes the captions that start inside it into its new length, so they do not overlap the next ones; an approved caption there blocks the fix ("un-approve it first"). Lengthening leaves captions in place.
- If a render fails (for example the browser could not be started), the version is kept without a video and the result page offers "Render again".
- "Start over" returns to the new-video form; earlier videos stay in the project's `.vea/videos/`.
- A fix changes the timeline as a patch and renders the whole video again; the untouched segments are identical in content to the previous version.

## Engines

- `builtin`: the built-in Remotion renderer. Available. Supports cut/fade/slide/zoom transitions, push in/out effects and line or word-by-word captions. The default caption font is Be Vietnam Pro (bundled, covers Vietnamese diacritics).
- `capcut`: a CapCut draft engine is planned but is not in this version; the UI shows it as unavailable.

## Privacy

Full media files never leave the machine. Only sampled frames (JPEG, 512 px wide) and transcripts (made locally by whisper.cpp) are sent to the Anthropic API, together with your prompt and `guideline.md`. Downloaded reference audio is used only when you say so explicitly.

One request carries at most 100 frames: every raw file keeps at least one, style references share at most 12, and the rest go to the raw files by shot count, spread evenly over each file. Shots without a frame are still listed (with their times) as text. The cost estimate counts only the frames that are sent.

During a render the media server listens on 127.0.0.1 only, answers only requests addressed to 127.0.0.1 or localhost on its port, serves files only under a random path that changes with every render, and never serves `.vea/` except downloaded samples.

## Known limits

- No speed ramps; a segment has one constant speed (0.75 to 1.5 in fixes).
- A fix re-renders the whole video.
- Transcription is local only (whisper.cpp).
- Remotion needs a paid company licence for organisations of more than three people. Check the Remotion licence terms before using this commercially.
- The first render on a machine downloads Remotion's browser and needs internet once. If that download fails, the job fails with "browser unavailable"; restart the app before using "Render again". `VEA_BROWSER` can point at a local Chrome or Chromium instead.
- The whisper.cpp and yt-dlp integrations were not exercised against the real binaries during development; they are covered by tests with fakes. Run `scripts/acceptance.ts` on real footage first.
- Output is 1080x1920, 30 fps, H.264/AAC; the default length is 15 to 90 seconds.

## Tests

```
npx vitest run            # whole suite, no network and no real AI
npx vitest run tests/e2e  # end-to-end: generate, fix one segment, revert (real renders, about a minute)
npx tsc --noEmit          # type check
```

Rendering tests need a browser for Remotion: either allow its one-time download or set `VEA_BROWSER` to a Chrome/Chromium executable.

## Manual acceptance run (real AI)

```
npx tsx scripts/acceptance.ts <projectDir> "<prompt>" ["<feedback>"]
```

It reads the AI key the same way as the app (`.env`, then the `AI_PROVIDER_KEY` environment variable), and the Whisper paths from `~/.vea/settings.json`. It runs prepare, generate and, if feedback is given, one fix, then prints the roles (with who decided each), the timing driver, the cost estimate, what was not followed, the output paths, and after a fix the ids whose content changed and whether the total duration changed. It exits with an error message if the key, ffmpeg or the Whisper binary is missing. With no arguments it prints its usage.
