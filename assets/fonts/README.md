# Fonts

Be Vietnam Pro, weights 400 and 700, Latin and Vietnamese subsets (woff2), the default caption font.

- Source: npm package `@fontsource/be-vietnam-pro@5.3.0` (files `be-vietnam-pro-{latin,vietnamese}-{400,700}-normal.woff2`).
- Copyright 2021 The Be Vietnam Pro Project Authors (https://github.com/bettergui/BeVietnamPro).
- Licence: SIL Open Font License 1.1, full text in `OFL.txt`.

The built-in renderer serves this folder's parent (`assets/`) as the Remotion public dir and loads the
fonts in `src/engines/builtin/remotion/fonts.ts`.
